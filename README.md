# Qwen Voxel Sandbox

A small, browser-based creative voxel sandbox with procedural terrain, block building, and desktop and mobile controls. No build step or account required.

## Play

https://h3902340.github.io/qwen-voxel-sandbox/

### Phone and tablet

Tap Start Game. Use the left joystick to move and drag the world with your other thumb to look. Tap Jump, Break, or Place. Select a block in the bottom hotbar. Pause, Save, and Load are at the top. Portrait and landscape layouts are supported.

### Desktop

Click Start, then WASD to move, mouse to look, Space to jump, left click to break, right click to place, and 1–7 to select blocks. Escape pauses/releases the pointer; click the world to resume. K saves, L loads, and R resets while paused. Save/Load buttons also work.

## Local development

Run `python3 -m http.server 8765` in this folder, then open http://localhost:8765. Assets use relative URLs so the game works under the GitHub Pages repository path.

## Saves and privacy

Worlds are saved only to this browser's localStorage, using a game-specific key. There is one save slot. Saves do not sync between devices, browsers, localhost, and GitHub Pages. Clearing browser storage removes them. The game has no analytics, accounts, or external API calls.

## Provenance and dependencies

The original gameplay was generated by local Ollama qwen3.6:35b and required supervised rendering/resume fixes. Subsequent assistant-written changes added mobile controls, responsive layouts, pointer cancellation and focus handling, save validation, and rendering cleanup. This is not an unmodified one-shot model output.

The only bundled third-party code is Three.js 0.160.1, under MIT; see THIRD_PARTY_NOTICES.md. Terrain, geometry, and colors are generated in code; no Minecraft assets are included. This project is not affiliated with Mojang or Microsoft.

## Verification and limitations

Chromium automated checks covered 390×844 portrait, 844×390 landscape, and 1280×800 desktop layouts; movement, touch look, jump, block actions, pause/resume, cancellation, save/load after reload, and focus loss. Browser-native emulated multi-touch additionally verified simultaneous move/look and pointer cancellation. Desktop automated pointer lock was simulated. These checks are not physical iPhone/Android testing.

This is a small, finite creative sandbox, not full Minecraft. No survival, crafting, mobs, multiplayer, or audio. Performance depends on the device. The original coarse collision/terrain behavior remains experimental.
